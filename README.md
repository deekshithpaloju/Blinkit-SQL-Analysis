Blinkit SQL Analysis Project
📌 Project Overview

The Blinkit SQL Analysis Project is a PostgreSQL-based database project designed to simulate a real-world quick-commerce platform similar to Blinkit. The project focuses on analyzing customer behavior, sales performance, product demand, revenue trends, and city-wise order patterns using SQL queries and relational database concepts.

🎯 Objectives
Design a normalized relational database.
Analyze customer purchasing behavior.
Evaluate product and category performance.
Generate revenue and sales insights.
Practice advanced SQL concepts including JOINs, Subqueries, Aggregate Functions, and Window Functions.
🛠️ Technologies Used
PostgreSQL
SQL
pgAdmin 4
📂 Database Schema
Customers Table

Stores customer information such as customer ID, name, and city.

Products Table

Contains product details including category and price.

Orders Table

Stores order-level information and customer references.

Order Items Table

Tracks products purchased in each order along with quantities.
